# 最终模型与恢复状态验收

## 目的
确认正式训练产物能恢复、数值有限且能够Prefill/Decode。

## 执行方案
在MiniMind根目录、训练所用PyTorch环境执行。先用nvidia-smi检查GPU5/7空闲；改变GPU时两张必须来自前四卡或后四卡的同一组。

```bash
MODEL=out/ep6_top2_compile_20261009/pretrain_ep6_top2_compile_20261009_768_moe.pth
CONFIG=out/ep6_top2_compile_20261009/training_config.json
RUN=runs/ep6_top2_acceptance_20261011
```

重复执行时选择新的输出目录，不覆盖已完成记录。

```bash
CUDA_VISIBLE_DEVICES=5,7 OMP_NUM_THREADS=1 python -m torch.distributed.run --standalone --nproc_per_node=2   --module tests.ep.validate_trained_checkpoint   --checkpoint "$MODEL" --training-config "$CONFIG" --resume-dir checkpoints   --output "$RUN/validation_new" --prepend-bos
```


## 结果
完整模型219个checkpoint张量全部有限、8层×6专家×3投影的NK形状完整。两Rank各585个恢复文件张量有限；epoch=1（从0计）、step=19848、world_size=2，AdamW状态已实际load_state_dict。恢复文件模型值与完整导出的相应子集逐元素相同，共享Embedding/LM Head保持同一参数。未执行优化器更新。

每Rank完成输入长度1/17/128/340的Prefill及一次缓存Decode，输出有限；3个提示各生成16个Token。首轮未加训练BOS时出现单词重复；补齐BOS后恢复连续续写。哈尔滨相关回答仍出现地理错误，这些探针不替代验证集质量评估。

## 调整闭环
首轮生成探针漏加训练使用的BOS，补测输入格式后单词重复消失；不能据缺BOS的探针断定训练失败。模型存在常识错误，后续单独评估验证集loss和标准生成；本轮不更改权重或训练。

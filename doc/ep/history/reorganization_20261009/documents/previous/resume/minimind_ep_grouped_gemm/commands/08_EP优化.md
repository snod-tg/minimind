# EP 优化具体指令

## 目的
构建最终算子，复验参数、数值、自动求导、安全及同轮性能。

## 执行方案
以下在 Server-Internet 执行；使用可导入 torch 的 TileLang venv，SCVideo 只提供 GCC12 编译器。

```bash
cd /data/user4/tongleiwen/minimind-ep-grouped-baseline-20261007/stage08_ep_20261009
source /data/user4/tongleiwen/tilelang-3032/.venv/bin/activate
export CXX=/data/share/home/user4/.conda/envs/SCVideo/bin/x86_64-conda-linux-gnu-c++
export OMP_NUM_THREADS=1
python build_api.py --source source --output results/REPRO_ep_build
LIB=results/REPRO_ep_build/my_cuda_ep.so
CUDA_VISIBLE_DEVICES=1 python validate_configuration.py --library "$LIB" --output results/REPRO_configuration.json
bash run_configurations.sh "$LIB"
CUDA_VISIBLE_DEVICES=1,3 python -m torch.distributed.run --standalone --nproc_per_node=2 validate_ep.py --experts 6 --library "$LIB" --output results/REPRO_full_model
for TOOL in memcheck racecheck synccheck; do
  CUDA_VISIBLE_DEVICES=1 /usr/local/cuda/bin/compute-sanitizer --tool "$TOOL" --error-exitcode 99 python validate_configuration.py --quick --library "$LIB" --output "results/REPRO_${TOOL}.json"
done
python run_measured_variants.py --library "$LIB" --output results/REPRO_variants --gpus 1,3 --rounds 21
python plot_ep.py --input results/REPRO_variants --output results/figures/REPRO_ep_routing.png
```

run_configurations.sh 使用 1/3/4 Rank 小模型，对应 GPU 列表可按空闲设备修改；性能只在 GPU 空闲且数值/安全测试结束后执行。性能输出使用未存在的新目录。Compute Sanitizer 必须返回 0，否则不进入训练。

## 结果
最终构建 R27 SHA256：0105cf9ef5171c1680909124c34b5c47c70c0c7ebd04f3358b87845c25204324。R28 配置 716 项、R26 多 Rank、R29 原尺寸模型、R30 三类安全检查及 R31 独立性能复测完成。

## 调整闭环
每次改动先运行受影响的数值测试；修改运行时分桶后补三类安全检查；只在源码稳定后独立计时。对 Top-K>2 记录原生重复运行波动，不将数学等价直接当作 BF16 逐位等价。
